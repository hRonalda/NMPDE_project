# Project 2 — v2.0 Enhancements

## Branch

`v2.0-enhancements`

This branch extends the baseline working solver saved in:

`v1.0-basic`

The purpose of this branch is to improve the visualization, run the wave solver on a larger domain, and start analyzing amplitude decay under mesh refinement.

---

## 1. Motivation

The baseline version `v1.0-basic` solved the 2D wave equation on the unit square:

`Ω = [0,1]^2`

with initial condition:

`u0(x,y) = x(1-x)y(1-y)`

This was useful for checking the implementation and verifying that the ParaView output worked correctly.

In this enhancement branch, we move to a larger domain:

`Ω = [-5,5]^2`

and use a Gaussian initial displacement:

`u0(x,y) = exp(-(x^2+y^2)/4)`

This gives a smoother and more visually meaningful wave-like test case.

---

## 2. PDE Problem

We solve the 2D wave equation:

`u_tt - Δu = f    in Ω`

`u = 0            on ∂Ω`

`u(0) = u0        in Ω`

`u_t(0) = u1      in Ω`

For the current test case:

`Ω = [-5,5]^2`

`f = 0`

`u0(x,y) = exp(-(x^2+y^2)/4)`

`u1(x,y) = 0`

The Gaussian initial condition has maximum value:

`u0(0,0) = 1`

Therefore, the expected initial infinity norm is:

`||u(0)||∞ = 1`

The terminal output confirms this.

---

## 3. Numerical Method

The finite element semi-discretization gives:

`M U_tt + K U = F`

where:

`M_ij = ∫Ω φ_i φ_j dx`

`K_ij = ∫Ω ∇φ_i · ∇φ_j dx`

The solver uses:

`Space discretization: Q1 finite elements on quadrilateral mesh`

`Time discretization: central difference method`

`Boundary condition: homogeneous Dirichlet`

`Output: .vtu snapshots + .pvd ParaView time-series file`

The central difference scheme is:

`M U^{n+1} = 2 M U^n - M U^{n-1} - Δt^2 K U^n + Δt^2 F^n`

For the current test case, `F = 0`.

---

## 4. Current Simulation Setup

`Domain: [-5,5]^2`

`Final time: T = 1`

`Time step: Δt = 0.01`

`Initial condition: u0(x,y) = exp(-(x^2+y^2)/4)`

`Initial velocity: u1 = 0`

The solver was tested with refinement levels:

`n_refine = 3, 4, 5`

The mesh size is computed using the domain length 10:

`h = 10 / 2^n_refine`

---

## 5. Mesh Refinement / Amplitude-Loss Study

The script:

`convergence_study.py`

runs the solver for different refinement levels and measures the infinity norm at the initial and final times.

The amplitude-loss indicator is defined as:

`Amplitude loss (%) = (||u(0)||∞ - ||u(T)||∞) / ||u(0)||∞ × 100`

This is not a rigorous convergence error, because no exact solution or reference solution is used. It is only an indicator of amplitude decay.

---

## 6. Results

| n_refine | Cells | DoFs | h | ||u(0)||∞ | ||u(1)||∞ | Amplitude Loss |
|---:|---:|---:|---:|---:|---:|---:|
| 3 | 64 | 81 | 1.2500 | 1.000000 | 0.518697 | 48.13% |
| 4 | 256 | 289 | 0.6250 | 1.000000 | 0.557631 | 44.24% |
| 5 | 1024 | 1089 | 0.3125 | 1.000000 | 0.568388 | 43.16% |

The results show that as the mesh is refined, the final maximum amplitude increases and the amplitude-loss indicator decreases.

This suggests that finer meshes reduce artificial amplitude decay and better preserve the wave amplitude.

---

## 7. ParaView Visualization

The output is visualized by opening:

`solution.pvd`

in ParaView.

For a 3D surface visualization:

`Filters -> Alphabetical -> Warp By Scalar`

`Scalars -> u`

`Scale Factor -> 5 or 10`

`Apply`

The computational mesh is still two-dimensional. The apparent 3D surface is only a visualization:

`z = scale_factor * u(x,y,t)`

The PDE is not solved in 3D. The z-axis represents the scalar displacement value.

At `t = 1` for `n_refine = 5`, ParaView shows a maximum value around:

`5.7e-01`

which agrees with the terminal result:

`||u(1)||∞ = 0.568388`

---

## 8. Interpretation

The Gaussian initial displacement starts with maximum value 1 at the center. Over time, the wave spreads outward, so the maximum value decreases.

The decrease in `||u||∞` is partly physical, because the wave spreads over the domain, and partly numerical, because the discretization introduces amplitude and phase errors.

Therefore, this study should be described as:

`mesh refinement study of amplitude decay`

not as a full convergence study.

A true convergence study should compare the numerical solution with either:

1. an exact manufactured solution, or
2. a very fine reference solution,

using an error norm such as:

`||u_h(T) - u_exact(T)||_L2`
